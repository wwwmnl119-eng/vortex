Строй на Vortex API

Полный REST API и WebSocket для интеграции мессенджера в твои проекты. Аутентификация через JWT.

📖 Документация 🟢 Статус API
Быстрый старт — авторизация 
// 1. Регистрация / вход
const res = await fetch('https://vortex-w2br.onrender.com/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: 'user@mail.com', password: '••••••' })
});
const { token, user } = await res.json();

// 2. Использование токена
const chats = await fetch('/api/chats', {
  headers: { 'Authorization': `Bearer ${token}` }
}).then(r => r.json());

WebSocket Events

Подключение через Socket.IO с JWT auth

Socket.IO подключение 
import { io } from 'socket.io-client';

const socket = io('https://vortex-w2br.onrender.com', {
  auth: { token: 'ваш_jwt_токен' }
});

// Получить сообщение
socket.on('new_message', (msg) => console.log(msg));

// Отправить сообщение
socket.emit('send_message', { chatId, content: 'Привет!' });

// Реакция на сообщение
socket.emit('react_message', { messageId, chatId, emoji: '👍' });

// Закрепить сообщение
socket.emit('pin_message', { messageId, chatId, pinned: true });
